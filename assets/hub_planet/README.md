# Meridian — Hub homeworld

An Earth-like ocean planet beneath Meridian Colony, with green continents,
polar ice, reflective oceans, drifting cloud systems, a thin blue atmosphere,
and restrained night-side settlement lights. Built in Blender 5.2 with surface
and cloud sources generated by the built-in ImageGen tool.

## Source and game assets

- `homeworld.blend`: editable Blender source with packed textures and a Cycles sun-lit preview.
- `homeworld.glb`: 13.25 MB, embedded PBR maps, 65,024 surface triangles and 36,480 cloud triangles.
- `homeworld.data.js`: equivalent embedded asset for direct-file play and binary-download failure.
- `textures/homeworld_albedo.jpg`: 4096 × 2048 surface color, without baked directional illumination.
- `textures/homeworld_clouds.png`: 4096 × 2048 opacity source, packed into the GLB cloud material's alpha.
- `textures/homeworld_normal.png`, `homeworld_roughness.png`, and `homeworld_cities.png`: 2048 × 1024 material maps.
- `source/imagegen-homeworld.png` and `source/imagegen-clouds.png`: original 1774 × 887 ImageGen outputs.
- `source/imagegen-prompt.json` and `source/imagegen-cloud-prompt.json`: exact prompts and tool provenance.
- `preview.html`: interactive globe viewer, with orbit, zoom, night-side, and cloud controls.
- `previews/holding-station.png` and `previews/hub-colony.png`: renders of the integrated game scene.

The 4K deliverables are Blender bakes from the supplied ImageGen maps, with
seam/pole treatment and additional procedural land grain. The ImageGen sources
are 1774 × 887; the bakes do not imply native 4K generated geography. The surface
resembles Earth's geography but is a visual game asset, not an authoritative map.

## Integration

The planet has radius 320,000 game units and centre `[150000, -430000, -360000]`.
The top of its atmosphere remains below the Hub's traffic altitude envelope.
The closest station has over 158,000 units of clearance after allowing for its
ring radius. The Hub retains station-centred movement and zero central gravity;
the visible globe has an offset spherical collision boundary.

The Hub sun direction frames a sunlit homeworld beneath the colony. The lighting
controller now accepts an offset planet centre, including solar occlusion.
Meridian's holding camera keeps the colony and planet beyond the carrier.
Existing saves inside the new globe move safely to the carrier's holding point.

Only a Hub visit loads the homeworld asset. Geometry and textures are cached
once per session; per-visit materials are released on departure. Failed binary
loading uses the script package; if both paths fail, a procedural blue/green
planet and atmosphere remain visible. Pending loads cannot revive an old zone.

## Rebuild and checks

Run Blender with `-b -t 8 --python-exit-code 1 -P assets/hub_planet/build_homeworld.py`,
then run `node assets/hub_planet/package_asset.cjs`.

Run `node tests/hub-planet-integration.cjs http` for the actual game, material
layers, offset collisions and eclipses, holding-camera framing, station/traffic
clearance, safe old-save placement, repeated visits, and rapid zone changes.
The `file`, `script`, and `missing` modes check direct-file play and fallbacks.
Validation reports record the exact tested HTML hash; tests use an isolated
browser and do not modify the player's saved game.
